# 🏰 AdventureGame

스파르타 내일배움캠프에서 Unity3D 과제로 진행한 개인 프로젝트입니다. ALT F4라는 게임과 유사하게 여러 가지 기믹을 피하며 나아가는 게임입니다. 3D 프로젝트에 필요한 요소들을 직접 구현해보면서 공부하기 위해 제작했습니다.

## 개요

* **제목** : Adventure Game
* **개발 환경** : Unity 2022.3.17f1
* **인원** : 정창범 (1명)
* **개발 기간** : 2025.03.04 ~ 2025.03.11
* **주요 기능** : 캐릭터 이동, 벽에 매달리기, 동적 환경 조사, 다양한 아이템, 인벤토리와 장비 장착, 다양한 Map 기믹, AI 적 몬스터

## 기능

**1. 캐릭터 이동**
* `WASD`를 눌러 플레이어 캐릭터를 이동할 수 있습니다.
* `Space bar`를 눌러 점프할 수 있습니다.
* `Shift`를 누른 상태로 WASD를 누르면 스태미너를 소모하여 대쉬가 가능합니다. (스태미너가 다 닳으면 대쉬를 멈춥니다.)
> Input System을 이용하여 키입력을 받도록 구현했습니다.

---

**2. 벽에 매달리기**
* 점프한 상태로 벽에 부딪혔을 때 `F`키를 누르면 스태미너를 소모하여 벽에 매달릴 수 있습니다. (스태미너가 다 닳으면 떨어집니다.)
* 벽에 매달리면 이동은 할 수 없으나 점프는 할 수 있습니다.
* 벽에 매달리고 점프한 후 지면에 닿을 때 까지 다시 매달릴 수 없습니다.
> Raycast를 활용하여 벽과의 충돌을 판단하고 Input System으로 키입력을 받아 매달릴 수 있도록 구현했습니다.

---

**3. 동적 환경 조사**
* 플레이어가 바라보는 오브젝트의 정보를 UI에 표시합니다.
* 상호작용 가능한 오브젝트를 조사하면 상호작용 키를 알려줍니다.
* `E`를 눌러 상호작용할 수 있습니다.

![image](https://github.com/user-attachments/assets/075162a4-b368-4e2a-812b-5bd91f9076ab)  
> 상호작용 가능한 오브젝트에 IInteractable이라는 인터페이스를 상속시켜 구현했습니다.

---

**4. 다양한 아이템**
* 장비 아이템과 소비아이템이 존재합니다.
* 소비아이템은 획득 즉시 사용됩니다.
* 장비아이템은 힉득하면 인벤토리에 들어갑니다.

![image](https://github.com/user-attachments/assets/924a5acb-ad82-4687-9338-8e8b9fbfdd03)
![image](https://github.com/user-attachments/assets/3736ed35-a1b5-45bf-8cb7-d66351691472)  
> ScriptableObject를 활용하여 다양한 아이템의 데이터를 관리할 수 있도록 구현했습니다.

---

**5. 인벤토리와 장비 장착**
* `Tab`을 눌러 인벤토리를 활성화 시킬 수 있습니다.
* 인벤토리 슬롯을 클릭하면 outline이 활성화되며, 해당 아이템의 정보가 나옵니다.
* 장착버튼을 눌러 장비를 장착할 수 있으며, 장비를 장착하게 되면 인벤토리에 장착 중인 아이템에 E(장착중) 표시가 나오며, 해당 아이템의 효과가 적용됩니다. 

![image](https://github.com/user-attachments/assets/662d5604-faea-443c-8933-7c4920488393)
> Inventory의 slot들을 배열로 저장하여, 아이템 획득시 slot에 아이템 정보를 저장하고 각각 관리할 수 있도록 구현했습니다.

---

**6. 다양한 Map 기믹**
* 플레이할 때 도움이 되거나 방해가 되는 다양한 Map 기믹들을 구현했습니다.  

  1. **점프대**  
    플레이어가 밟으면 높게 점프합니다.  
      > Rigidbody의 AddForce를 활용하여 구현했습니다.  

  2. **레이저 트랩**  
    플레이어가 보이지않는 레이저에 닿으면 앞에서 공이 굴러옵니다.  
      > Raycast를 활용하여 구현했습니다.

  3. **움직이는 플랫폼**  
    플레이어가 밟고 지나가야하는 움직이는 발판입니다.  
      > DOTween으로 부드럽게 움직이도록 구현했습니다.  

  4. **고속 이동 장치**  
    상호작용하면 플레이어를 정해진 위치로 날려줍니다.  
      > Rigidbody의 AddForce를 활용하여 구현했습니다.  

---

**7. AI 적 몬스터**
* 주변을 돌아다니다가 플레이어가 탐지 범위안에 들어오면 달려와서 공격하는 몬스터입니다.
* 플레이어를 따라가던 도중 플레이어가 탐지 범위 밖까지 멀어지면 다시 주변을 돌아다니게 됩니다.
> Navigation System을 활용하여 구현했습니다.
